# SoulsPlanner DPS Scripts
This repository contains Tampermonkey scripts that add DPS-related calculations to SoulsPlanner weapon tables.

The scripts are intended to provide a simple, consistent way to compare weapon DPS using the data shown on SoulsPlanner.

- Extend SoulsPlanner weapon tables with additional DPS columns
- Use weapon attack values and game-specific speed data
- Calculate DPS in a uniform way for comparison purposes
- Automatically update when values on the page change

Each game has its own folder and scripts, based on that game’s mechanics and data.

## How to use
1. Install Tampermonkey  
   https://www.tampermonkey.net
2. Open a script from this repository.
3. Create a new Tampermonkey script and paste the code.
4. Save the script.
5. Open the corresponding SoulsPlanner weapon page.
- Dark Souls 1: https://soulsplanner.com/darksouls/weaponatk
- Dark Souls 3: https://soulsplanner.com/darksouls3/weaponatk
7. Reload the page to see the added DPS information.
